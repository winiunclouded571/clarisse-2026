## 🔧 Troubleshooting Tips

If you encounter issues, try these common fixes:

- **Installation fails:** Run the installer as Administrator (right-click > Run as Administrator)
- **Software crashes on launch:** Update your graphics card drivers
- **Slow performance:** Reduce render quality settings or close other applications
- **Missing textures:** Ensure all texture files are in the correct project folder
- **Cannot open project files:** Check that you're using the correct version of Clarisse
